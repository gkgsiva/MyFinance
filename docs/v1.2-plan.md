# MyFinance v1.2 plan

Pure logic lives in `core/` (tested with `./gradlew -p core test`); the Android parts are built on top of v1.1.

| # | Feature | Core (done) | App work |
|---|---------|-------------|----------|
| 1 | Goals and savings targets | `Goals.kt`: progress %, per-month needed, on track / behind / overdue | Goals screen, add money to a goal, link a goal to a savings account |
| 2 | Investments and net worth | `NetWorth.kt`: SIP/MF/FD/RD/stock/PPF/NPS SMS parser, holdings, net worth with loans | Net worth screen, holdings editable by hand, SMS hook adds events |
| 3 | Bill reminders | `BillReminders.kt`: due states, next cycle, match a payment SMS to a bill | Bills screen, daily WorkManager check, notifications; reuses v1.1 recurring code where possible |
| 4 | Split and settle | `Splits.kt`: equal shares to the paisa, balances, fewest settle-up payments | "Split" action on an entry, People screen with who owes whom, record settlement |
| 5 | Receipt photos | (app only) | Camera / gallery picker per entry, photos stored in app-private storage, included in backup |
| 6 | Cash wallet | `CashWallet.kt`: ATM withdrawals top up, cash spends draw down | Cash tab, quick "spent cash" entry |
| 7 | Tax helper | `TaxHelper.kt`: 80C/80CCD(1B)/80D/80E/80G/24(b) suggestions, FY (Apr–Mar) totals with limits | Tag entries with a section, yearly tax summary screen |
| 8 | App lock | `PinHasher` in `Security.kt`: salted PBKDF2 PIN, lockout | Fingerprint (BiometricPrompt) or PIN on open and after 1 minute in background; hides app in recents |
| 9 | Encrypted backup and restore | `BackupCrypto` in `Security.kt`: AES-256-GCM, password-derived key, gzip container | Backup to a file you pick (Drive, Downloads, pen drive) via the system file picker; restore merges with duplicate removal |
| 10 | Custom rules | `CustomRules.kt`: contains / regex on merchant, SMS text or sender; amount range; set category, rename, exclude, ignore, tax tag | Rules screen with a live "test against my SMS" preview; rules run before learnt merchant rules |

Privacy: everything stays on the phone. Backups are encrypted with a password only the user knows before they leave the app, and go only where the user saves them.
